# Galerie d'images

Toutes les images du dossier concept sont rangées ici **par sujet** : les croquis faits à la main,
les photos de la maquette et les visuels générés pendant la conversation d'origine se côtoient
dans le même dossier. Un fichier dont le nom finit par `-croquis` est un dessin ou une fiche
manuscrite ; les autres sont des rendus.

Les variantes (`-v1`, `-v2`…) sont conservées dans leur ordre de création pour garder la trace de
l'évolution du concept. Chaque fiche du dossier intègre déjà ses propres images ; cette page sert
d'index.
